Sentinel EOF

Cuts frontier LLM spend for agentic coding without sacrificing accuracy, via calibrated escalation rather than blanket downgrade.

The problem

Agentic coding pipelines typically send every subtask to a frontier model. That is simple to operate and expensive. A large share of those subtasks are well-specified and would pass on a cheaper local model.

Routing everything to a cheap model is not a fix. Failures are uneven: some easy tasks survive, others fail silently, and accuracy drops in ways that are hard to predict or bound. The useful question is not “cheap or frontier,” but which tasks need the expensive pass.

How it works

Escalate-on-fail cascade

  1. Cheap first pass. A local coding model, served with Ollama by default, attempts the subtask first. No frontier call is made unless this attempt is flagged.
  2. Calibrated failure signal. A signal scored on a held-out calibration split estimates whether that first pass is likely to fail. Thresholds are set on the calibration split only; the evaluation split is not used to tune them.
  3. Frontier only when flagged. Tasks the signal marks as high-risk escalate to a frontier model. Everything else ships the local result. This is escalation, not a global downgrade of model quality.

The production architecture is a single-leg cascade: one cheap attempt, then escalate or accept. That is the configuration that survived pre-registered kill criteria. Broader ensemble-disagreement variants were tested and did not replace it.

Validated results

Audited evaluation, not a marketing estimate

0.54

Cost ratio vs. always-frontier · n = 158 · no accuracy loss

On the held-out evaluation set (n = 158), Sentinel EOF spent approximately 0.54× the cost of sending every task to the frontier model, with no accuracy loss relative to that always-frontier baseline.

Kill criteria were written down before the run. Configurations that failed those criteria were discarded, including a later cheap-ensemble disagreement variant that did not beat this single-leg cascade on cost-adjusted accuracy. The 0.54 figure is the surviving production result, not a selected peak from an unregistered sweep.

Where else it applies

Domain-agnostic primitive

Escalate-on-fail is not a coding-only trick. The same primitive — attempt under a cheaper or faster policy, then escalate when a calibrated signal says the attempt is likely wrong — has been validated in AML alert triage and in quantitative trading.

Agentic coding is the first product vertical, not the whole architecture. Teams that already run high-stakes agent pipelines can evaluate the same control in more than one domain.
